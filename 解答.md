# Trio 后端技术解答

***

## 一、基础术语解释

在阅读之前，先理解这几个最基础的概念：

| 术语                 | 用大白话说                                      | 在本项目中                                              |
| ------------------ | ------------------------------------------ | -------------------------------------------------- |
| **后端 (Backend)**   | 手机上 APP 的"大脑"。APP 只是展示界面，所有数据计算和存储都由后端完成。  | `backend/` 文件夹里的一套程序，用 NestJS 框架编写                 |
| **服务器 (Server)**   | 就是一台一直开机的电脑，跑着后端程序，等 APP 发请求过来             | 你的电脑（运行 `npm run start:dev` 时），监听 **3000 端口**      |
| **数据库 (Database)** | 一个"超级表格"，所有用户、消息、群组等信息都存在这里                | `backend/prisma/dev.db` 这个文件，是 **SQLite** 数据库      |
| **API (接口)**       | APP 和后端之间"对话"的方式。APP 说"给我消息列表"，后端返回数据      | 一个网址，比如 `http://192.168.0.111:3000/messages/chats` |
| **JWT (令牌)**       | 登录后拿到的一张"门禁卡"，之后每次访问都要出示它                  | 一串加密字符串，有效期 24 小时                                  |
| **WebSocket**      | 和 API 不同，API 是"问一句答一句"，WebSocket 是"一直通着电话" | 用于实时推送：新消息提醒、在线状态、对方正在输入...                        |

## 二、从哪里访问？

### 2.1 访问地址

| 访问者             | 地址                          | 说明            |
| --------------- | --------------------------- | ------------- |
| **Android 模拟器** | `http://10.0.2.2:3000`      | 模拟器内特殊地址，指向电脑 |
| **真机（同一 WiFi）** | `http://192.168.0.111:3000` | 你的电脑局域网 IP    |

### 2.2 如何启动后端

```bash
cd backend
npm install          # 第一次需要：安装依赖包（等于给程序装零件）
npm run start:dev    # 启动后端（开发模式，修改代码自动重启）
```

启动成功后终端会显示：

```
Trio Backend running on http://0.0.0.0:3000
```

## 三、三大核心组件

### 🔷 组件 1：REST API（HTTP 接口）

**干什么用的：** APP 通过 HTTP 请求来增删改查数据。就像你用浏览器打开网页，但返回的是 JSON 数据而不是页面。

**所有 API 路由一览表：**

| 方法     | 完整地址                                           | 功能                | 需要登录  |
| ------ | ---------------------------------------------- | ----------------- | ----- |
| POST   | `http://IP:3000/auth/register`                 | 注册新用户             | ❌ 不需要 |
| POST   | `http://IP:3000/auth/login`                    | 登录，拿 JWT 令牌       | ❌ 不需要 |
| GET    | `http://IP:3000/users/me`                      | 查看自己的信息           | ✅ 需要  |
| PATCH  | `http://IP:3000/users/me`                      | 修改自己的信息（昵称/头像等）   | ✅ 需要  |
| PATCH  | `http://IP:3000/users/me/fcm-token`            | 更新 FCM 推送令牌       | ✅ 需要  |
| GET    | `http://IP:3000/users`                         | 获取所有用户列表（支持搜索）    | ✅ 需要  |
| GET    | `http://IP:3000/users/:id`                     | 查看某个用户的信息         | ✅ 需要  |
| POST   | `http://IP:3000/messages`                      | 发送一条消息            | ✅ 需要  |
| GET    | `http://IP:3000/messages/chats`                | 获取聊天列表（所有私聊+群聊预览） | ✅ 需要  |
| GET    | `http://IP:3000/messages/user?otherUserId=xxx` | 获取和某人的私聊记录        | ✅ 需要  |
| GET    | `http://IP:3000/messages/group?groupId=xxx`    | 获取某群的消息记录         | ✅ 需要  |
| POST   | `http://IP:3000/groups`                        | 创建新群组             | ✅ 需要  |
| GET    | `http://IP:3000/groups`                        | 获取我加入的群组列表        | ✅ 需要  |
| GET    | `http://IP:3000/groups/:id`                    | 查看某个群组的详情         | ✅ 需要  |
| PATCH  | `http://IP:3000/groups/:id`                    | 修改群组信息（群名等）       | ✅ 需要  |
| POST   | `http://IP:3000/groups/:id/members`            | 往群里加人             | ✅ 需要  |
| DELETE | `http://IP:3000/groups/:id/members/:userId`    | 从群里踢人             | ✅ 需要  |
| DELETE | `http://IP:3000/groups/:id`                    | 删除群组              | ✅ 需要  |
| GET    | `http://IP:3000/moments`                       | 获取所有动态            | ✅ 需要  |
| POST   | `http://IP:3000/moments`                       | 发一条动态             | ✅ 需要  |
| POST   | `http://IP:3000/moments/:id/like`              | 给某条动态点赞/取消点赞      | ✅ 需要  |
| POST   | `http://IP:3000/upload`                        | 上传文件（头像等）         | ✅ 需要  |

> **"需要登录"** 意味着：APP 必须在请求头里带上 JWT 令牌，否则后端会拒绝。

***

### 🔶 组件 2：WebSocket（实时通信）

**干什么用的：** 让消息能"秒到"，不用 APP 反复刷新。还有在线状态、对方正在输入等功能。

启动地址：`http://IP:3000`（Socket.IO 复用同一端口）

| 事件名（APP 发出的）   | 功能                     |
| -------------- | ---------------------- |
| `authenticate` | 告诉后端"我是谁"，加入实时通道       |
| `sendMessage`  | 通过 WebSocket 发消息（实时投递） |
| `markAsRead`   | 标记消息已读                 |
| `typing`       | 告诉对方"我正在输入..."         |
| `stopTyping`   | 告诉对方"我停止输入了"           |
| `joinGroup`    | 加入某个群的实时频道             |
| `leaveGroup`   | 离开某个群的实时频道             |

| 事件名（后端推给 APP 的） | 功能       |
| --------------- | -------- |
| `newMessage`    | 收到新消息    |
| `userOnline`    | 某用户上线了   |
| `userOffline`   | 某用户下线了   |
| `typing`        | 某人正在输入   |
| `stopTyping`    | 某人停止输入   |
| `messagesRead`  | 消息已被对方阅读 |

***

### 🔷 组件 3：Firebase Admin（云端推送 + 数据同步）

**干什么用的：**

1. **FCM 推送** — 即使 APP 在后台/被杀了，也能让手机收到通知提醒
2. **Firestore 同步** — 把 SQLite 里的用户和消息数据单向复制到 Google 云端，给 Admin 看板读取

| 功能           | 说明                                             |
| ------------ | ---------------------------------------------- |
| FCM 推送       | 代码已写好，但要装 `google-services.json` 配置文件才能用       |
| Firestore 同步 | 后端自动把注册用户和消息写到 Firestore，Admin 看板从 Firestore 读 |

## 四、数据库里有什么？（SQLite）

数据库在 `backend/prisma/dev.db`，由 **Prisma ORM** 管理。里面有以下"表"：

| 表名                   | 存什么数据    | 主要字段                                                           |
| -------------------- | -------- | -------------------------------------------------------------- |
| **User**（用户）         | 所有注册账号   | id, username, email, password(加密), role, avatar, bio, isActive |
| **Message**（消息）      | 所有聊天记录   | id, content, image, senderId, receiverId, groupId, isRead      |
| **Group**（群组）        | 所有群      | id, name, avatar, creatorId                                    |
| **GroupMember**（群成员） | 谁在哪个群    | userId, groupId, role(MEMBER/ADMIN)                            |
| **Task**（任务）         | 团队任务     | title, description, status, assigneeId                         |
| **Approval**（审批）     | 审批流程     | title, description, status, applicantId, approverId            |
| **Announcement**（公告） | 系统公告     | title, content                                                 |
| **Moment**（动态）       | 朋友圈动态    | content, userId                                                |
| **MomentLike**（点赞）   | 谁给哪条动态点赞 | momentId, userId                                               |

**怎么查看数据库内容？**

推荐用 **Prisma Studio**（浏览器图形界面）：

```bash
cd backend
npx prisma studio
# → 浏览器打开 http://localhost:5555
```
